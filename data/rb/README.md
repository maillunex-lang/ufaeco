# Данные региона: Республика Башкортостан

| Файл | Содержание | Достоверность |
|---|---|---|
| `geo.json` | Контур РБ и реки Белая/Урал | Natural Earth (общественное достояние), упрощено |
| `cities.json` | 21 город: координаты, население, зарплаты, цена земли, пригодность земли, специализация, параметры плана города | **Приближённо.** Координаты округлены; население (перепись 2021) округлено; зарплаты, цены на землю и индекс пригодности — гипотезы |
| `resources.json` | Природные ресурсы: нефть, медно-цинковые и золотые руды, железо, известняк, лес, песок/глина | **Условно.** Районы по общим сведениям, запасы и качество — гипотезы игры |
| `transport.json` | Схема автодорог и железных дорог, хабы (внешний рынок), параметры фрахта | **Схематично.** Не точная геометрия сетей |

Все файлы проверяются валидатором (`server/src/region/data.ts`, тест `tests/region.test.ts`). Названия компаний и брендов не используются.
Перед релизом приближённые значения нужно сверить с Башстатом, открытыми данными и геологическими источниками.
